# Platform policy matrix

Verified against linked official sources on 2026-11-22. This is a release checklist, not a legal certification. Recheck permissions and pricing before activation.

| Platform | Permitted path and authentication | Prohibited or gated | Cost and owner approval |
| --- | --- | --- | --- |
| Upwork | Official remote MCP via OAuth 2.1 for supported discovery, job details, draft proposals and permitted account reads. Separate approved API only within authorized scopes. | No scraping, browser session reuse, background polling, automated proposals, messages, Connects use, or Catalog writes via MCP. Keep platform-origin transactions on-platform. | MCP is described as free for account holders; rate and account limits apply. Connects and contract fees apply independently. Owner authorizes OAuth and each external write. [MCP](https://www.upwork.com/ai/mcp) · [Automation rules](https://support.upwork.com/hc/en-us/articles/43342677368467) |
| Fiverr | Existing account, manual Gigs and manually recorded owner-side revenue facts. No generally available Gig write integration was verified. | No extraction of Fiverr job/order/chat data, browser automation, vended sessions, spam, external payment or off-platform contracts. | Free manual draft work; no promotions. Freelancer receives 80% of completed order value under standard terms. Owner reviews and publishes. [Gig guidance](https://help.fiverr.com/hc/en-us/articles/360010451397-Creating-a-Gig) · [Order tools](https://help.fiverr.com/hc/en-us/articles/360010639617-A-freelancer-s-guide-to-the-Fiverr-order-process) · [Earnings](https://help.fiverr.com/hc/en-us/articles/9234443621137) |
| Stripe Japan | Dashboard owner onboarding and official SDK test-mode APIs; project-scoped test API key and signed webhook secret. | No live charges, raw card data, invented identity or Stripe for marketplace fee avoidance. | Test mode only. Live processing fees are per transaction and not operating budget. Owner completes KYC, payout and legal approval. [Stripe Japan guide](https://support.stripe.com/questions/getting-started-with-stripe-a-guide-for-users-in-japan?locale=ja-JP) · [Japan pricing](https://stripe.com/jp/pricing) |
| Google Search Console and GA4 | Owner verifies URL-prefix property; private Google account, least-privilege Viewer/API read access. | No PII in events, ad enablement, offline upload of inquiries/payment IDs, or BigQuery activation here. | Existing standard browser reports only. Data APIs have quotas. Use without exporting to billed storage. [GA4 quotas](https://developers.google.com/analytics/devguides/reporting/data/v1/quotas) · [Search Console](https://support.google.com/webmasters/answer/9008080) |
| Google Business Profile | Owner confirms eligibility, verifies profile, requests official OAuth/API access and grants narrow role. | No profile for an ineligible online-only business, synthetic reviews, incentives, or unapproved replies. | Manual account feature; API access and quotas must be checked before activation. [Eligibility](https://support.google.com/business/answer/3038177) · [API prerequisites](https://developers.google.com/my-business/content/prereqs) |
| X | Draft offline; future documented API with owner OAuth and approved access level. | No paid API plan, unauthorized automation, spam, or publishing. | No verified zero-cost posting architecture approved. [X automation rules](https://help.x.com/en/rules-and-policies/x-automation) |
| Instagram | Owner-managed Meta professional account; official Graph API and eligible app permissions after review. | No unauthorized scraping, private endpoints, or unapproved publishing. | No API use authorized. Review app permissions and quotas before activation. [Instagram Platform](https://developers.facebook.com/docs/instagram-platform/) |
| LINE | Owner-created Official Account; official Messaging API channel credentials and scoped, authorized notifications. | No default outbound messages, purchases, or consent bypass. | Japanese plan quotas vary and must be verified against actual account. [LINE pricing](https://developers.line.biz/en/docs/messaging-api/pricing/) |
| GitHub Pages / Google Calendar | Existing public portfolio and public appointment page. Use Google-hosted availability; leave private calendar private. | No payment processing or business-operation endpoints on Pages. | Existing setups only; no upgrade, registration, or extra plan. [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) · [Appointment schedules](https://support.google.com/calendar/answer/11608416) |
| Cloud Run / BigQuery / Supabase / email | Local execution and mock delivery are approved. Production adapters require scoped identities, configuration review, and owner enablement. | No new billable resources, chargeable exports, live email or unsafe management tokens. | See the [zero-cost assessment](../architecture/cost-controls.md) and [reporting runbook](../reporting-setup.md). |
| Local AI / OpenAI | Deterministic rules always available; optional on-device llama.cpp with an existing GGUF. | No credentials to local models, remote proposal submission, or paid API activation. | No API subscription assumed. OpenAI adapter stays disabled. Local compute uses existing hardware and electricity. |
